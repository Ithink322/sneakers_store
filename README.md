# О проекте

Проект большой, это онлайн магазин продажи обуви. Написан на HTML, SCSS, Vue3/Nuxt3 + Typescript с Pinia на фронтенде, как база данных используется MongoDB, mongoose, JWT на бэкенде. В нём есть главная страница со множеством слайдеров, есть слайдер с автосвайпами - https://sneakers-storee.netlify.app/, но это не так интересно всё. Есть куда более интересные страницы, как например, страница блога с админкой на редактирование/добавление/удаление блог постов - https://sneakers-storee.netlify.app/blog/все-публикации?page=1, где также можно переключаться между категориями постов в дропдауне справа. Есть каталог товаров со множеством фильтров и сортировок - https://sneakers-storee.netlify.app/catalog?page=1, он также с админкой, где можно добавлять/редактировать/удалять товары. У каждого товара можно оставить отзывы, которые отображаются на странице товара на вкладке отзывы, под изображениями товара. Их также можно удалить, если ты авторизовался, как админ. Ещё из интересного есть личный кабинет, где можно просматривать свои заказы и редактировать личные данные - https://sneakers-storee.netlify.app/PrivateCabinet. Есть также меню избранного и корзина товаров с чекаутом и сообщением при успешном заказе. А самое крутое, что есть поиск по каталогу товаров в шапке сайта, где можно легко найти нужный товар.
